# WinUI 桌面格子

格子界面源自 DeskBox 提交 `4cae1d4ebb0e416af7d66a764f52f6ccaafdda3a`。`deskbox.patch` 保存 SoulDesk 对该提交的修改。原版许可为 GPL-3.0。分发独立格子程序时，需附带许可与对应的完整源码，其中包括上游源码和本补丁。[固定版本源码](https://github.com/Tianyu199509/DeskBox/tree/4cae1d4ebb0e416af7d66a764f52f6ccaafdda3a)

`scripts/build-desktop-grid-winui.ps1` 使用固定散列的上游 ZIP、本地 .NET 10 SDK 和 NuGet 包目录复现构建。脚本只生成工作区内的源码副本和运行目录。使用 `-PrepareOnly` 可单独校验并应用补丁。

设置目录由 `scripts/export-deskbox-settings.py <DeskBox 的 src/DeskBox 目录> <输出 JSON>` 从固定版本的设置窗口和分区模板提取。运行时仅加载目录中的界面描述。可用操作通过设置专用会话保存本地布局，其他控件显示禁用提示。

WinUI 从引擎读取名称、位置、折叠状态和成员。鼠标拖放、标签切换、拆组、手动折叠和完成定位都会提交请求，由引擎核对会话及布局版本后更新 `layout.json`。格子使用物理屏幕坐标和逻辑尺寸，位置保存使用对应的显示器组合。系统拖放回调完成后再等待引擎保存引用，确保拖放源能及时退出 Windows 的拖放循环。

「跟随默认」「悬停自动展开」「单击展开」「始终展开」按格子保存。旧布局沿用已有的悬停设置。标签切换、位置确认和展开方式变更复用同一格子窗口。位置保存保留折叠胶囊与展开面板的相对位置。未分组图标根据文件引用增减，位置或折叠配置变更时复用已有的图标控件。

管理窗口设置默认展开方式。格子菜单提交显示与隐藏、改名、独立锁定位置和大小、视图、排序、自动堆叠、目录打开方式、胶囊方向与宽度，以及标签的显示方式。已隐藏的格子可从管理列表恢复。布局 JSON 增量记录这些选项，旧版的合并锁和排序方向沿用原语义。对齐线使用 DeskBox 的窗口边缘计算，候选窗口来自当前格子会话。

自定义堆栈的成员、名称、顺序和分组设置写入布局。标题图标和背景图使用 DeskBox 原有选择器与渲染控件，图片副本保存在格子数据目录的 `artwork/widget-assets/`。显示器绑定、Ctrl 联动和胶囊栏依照原有位置计算接入当前会话。绑定的显示器离线时会先显示在可用屏，再按绑定恢复。

「桌面整理 → 预览搬移」会在确认后移动勾选的同盘项目。普通格子的目标文件夹位于 `organized/`，映射格子使用映射目录。整理历史位于 `organization-history.json`。每项操作先写入记录，再搬移原文件。恢复前核对原路径及文件内容。布局备份保存配置和引用，图片与搬移历史按本地数据目录管理。

引擎等待 WinUI 首帧及窗口归属校验通过，再交由独立守护进程接管 Explorer 图标。

生成独立的 SoulDesk 验收安装包时，使用 `scripts/build-desktop-grid-winui.ps1 -UpstreamArchive <上游 ZIP> -TestBundleRuntime <已构建的 bin 目录>` 生成配置。向 Tauri 构建命令传入 `--config <生成的配置>`。安装包包含格子运行文件、DeskBox 源码归档、修改补丁和许可证，使用独立名称和数据目录。

生成使用常规 SoulDesk 名称和应用标识的本地完整安装包时，使用同一脚本的 `-BundleRuntime <已构建的 bin 目录>` 生成配置，再传给 `node scripts/desktop.mjs build --config <生成的配置>`。此配置包含同一套格子资源和源码，适用于本地交付与隔离安装验收。
