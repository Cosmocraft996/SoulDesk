# SoulDesk · 桌面组件

Windows 首发的通用桌面组件宿主。以独立组件直接摆放在桌面上为主要使用方式，快捷键和侧边组件面板为补充，管理窗口负责添加与设置；币安行情与本地价格警报是第一个完整业务。

普通组件通过本地包独立导入；需要新的特殊后台能力时允许升级主程序。产品范围和技术实现分别维护，详见下方文档。
