# SoulDesk · 桌面组件

Windows 首发的通用桌面组件宿主。以独立组件直接摆放在桌面上为主要使用方式，快捷键和侧边组件面板为补充，管理窗口负责添加与设置；币安行情与本地价格警报是第一个完整业务。

普通组件通过本地包独立导入；需要新的特殊后台能力时允许升级主程序。产品范围和技术实现分别维护，详见下方文档。

## 当前状态

截至 2026-11-20，宿主源码为 0.5.5。新安装可从管理窗口「官方广场」下载组件，也可在「组件库」选择本地 ZIP 或将单个 ZIP 拖入导入区。已经登记的组件、实例和数据由原数据库与资源目录继续管理。

- Windows 安装包默认选择「保留用户数据安装」，也可选择「完全覆盖安装」，将旧数据移到同级备份目录后从空白数据启动。检测到 SoulDesk 正在运行时，确认后自动关闭，取消则返回安装方式选择。完成页可选立即启动。见 [12-安装方式与取消处理](docs/12-面板交互与自动更新.md#2026-11-19安装方式与取消处理)。
- 默认新增到侧边面板当前分组，再按需放到桌面。新增、恢复及移入组件均保持面板当前显隐和层级。
- 「应用设置 → 应用主题」可选择墨蓝、松烟、燕麦和雾紫。默认墨蓝，选择后即时应用并在下次启动时恢复。
- 「应用设置 → 通知」可分别开关 Windows 系统通知和灵动通知，默认都开启。组件可通过 SDK 指定渠道。久坐和计划来电走灵动通知，并受实例开关控制。组件开发入口见 [SDK 通知接口](sdk/README.md#组件通知notificationssend)。
- 桌面与侧边面板内的小组件默认内容铺满，鼠标移入或键盘聚焦时显示浮动工具栏。在「应用设置 → 组件外观」可开启宿主衬底，默认关闭。见[外观与业务入口](docs/02-技术方案与Codex实施指南.md#33-外观与业务入口)。
- 侧边面板按分组恢复滚动位置并优先加载视口附近的组件。12组件隔离对照中，重复展开首次可见的中位时间从2.11秒降至0.98秒，展开后私有内存从约563 MiB降至506 MiB。见 [12-侧边面板展开与滚动恢复](docs/12-面板交互与自动更新.md#2026-11-18侧边面板展开与滚动恢复)。
- 左键单击托盘图标或点击挂件均可开合面板，锁定时切换置顶和置底。未锁定时，鼠标移出面板或失焦 3 秒后收起，点击外部立即收起。锁定时，点击外部置底，直接解锁时提回置顶。快捷键或桌面空白双击可锁定并展开，或解锁并收起。挂件悬停约 200 毫秒可展开已收起的面板，并支持跨屏拖动及保存停靠位置。见 [12-收起、置顶与置底](docs/12-面板交互与自动更新.md#2026-11-19收起置顶与置底)。
