# SoulDesk 品牌视觉规范

2026-11-25 定稿采用「浮格蓝 · 面性」。品牌图形由一个 L 形底座与移向右上方的组件格组成。识别色为 **#64D0FF**。应用提供深色和浅色两套宿主配色，浅色界面用较深的 **#075C88** 表达同一种交互强调。

## 控件与宿主表面

- 主按钮用实色填充，按悬浮、按下状态使用对应填充色。主按钮上的文字和图标使用强调底文字。次要按钮和输入控件通过表面与控件边界建立层级。
- 当前导航、组件管理标签和分类使用选中染底，搭配强调色文字及已有选中语义。宿主的设置、搜索和通知等功能图标使用现有 Lucide 线性图标。
- 键盘焦点环宽 2 个逻辑像素，与控件相隔 2 个逻辑像素。禁用状态采用次要文字与控件底色，交互由原生禁用状态控制。
- 成功、警告和错误使用语义色，并配文字或图形标记。组件内部配色及行情涨跌约定由各组件维护。
- 设置、导航和包含文字的卡片使用实色表面。侧栏的画布染底跟随宿主主题，背景遮罩沿用独立滑杆和已有保存值。未配置时为 50%。设计评审中的深色 88%、浅色 92% 染底和 12 像素模糊用于比较，实际磨砂由 Windows 窗口与系统效果控制。低遮罩下，文字和持久控件放在实色表面上。
- 正文、次要文字和可用控件文字的对比度目标为 4.5∶1。用于识别操作的控件边界和焦点环目标为 3∶1。按实际邻接色核对，尤其是覆盖桌面壁纸的表面。[WCAG 2.2 对比度要求](https://www.w3.org/TR/WCAG22/#contrast-minimum)

「设置 → 外观」默认使用浮格蓝深色，沿用原墨蓝的 `ink` 保存值。浮格蓝浅色使用 `ice-light`。已有松烟、燕麦、雾紫的偏好继续有效。两个浮格蓝主题都随宿主变更事件切换，重启后按保存值恢复。

## 品牌图标

| 入口 | 资产 | 规则 |
| --- | --- | --- |
| 设置标题 | [深色与通用源稿](../src-tauri/icons/icon.svg)、[浅色源稿](../src-tauri/icons/icon-light.svg) | 深色用亮蓝实底和深色图形。浅色用深蓝实底和白色图形。 |
| 应用、任务栏、安装与卸载 | [Windows ICO](../src-tauri/icons/icon.ico) | 使用通用源稿。包含 16、24、32、48、64、256 像素帧。 |
| Windows 桌面快捷方式 | 安装目录的 souldesk-float-blue.ico | 随包安装同一份 ICO。保留数据升级时更新原有快捷方式的默认图标引用，保留启动属性与用户自选图标。 |
| Windows 通知标识 | [应用 PNG](../src-tauri/icons/icon.png) | 使用 512 像素透明应用图，由安装器登记。 |
| SoulDesk 主托盘 | [托盘源稿](../src-tauri/icons/tray.svg)、[托盘运行资源](../src-tauri/icons/tray.rgba) | 固定深蓝底 #182F4B 和淡蓝图形 #A9E5FF。使用实心剪影，按 16 像素检查，运行资源为 32×32、直通 RGBA，每像素四字节。 |

图标使用 100 单位的正方形画布。应用底板四周留 4 单位透明边距、圆角 21 单位。托盘底板占满画布、圆角 19 单位。图形和底板保持实色，保留两个形状之间的留白。深浅源稿共享图形坐标和尺寸。

更新通用源稿后，用仓库现有 Tauri 图标命令在隔离目录重新生成应用 ICO 和 PNG。随后同步 [打包资产](../src-tauri/tauri.conf.json) 引用的文件。更新托盘源稿时重新栅格化为 32×32 直通 RGBA，确认文件为 4096 字节，并对照浅色和深色任务栏检查 16 像素轮廓。[Windows 图标尺寸与场景](https://learn.microsoft.com/en-us/windows/apps/design/iconography/app-icon-construction)

## 验收

1. 在隔离数据中切换浮格蓝深浅主题，检查设置、组件管理、侧栏和桌面工具栏。重启后确认主题恢复，保存失败时界面保留原选择。
2. 检查设置标题的深浅图标、系统托盘、任务栏、通知、安装和卸载图标。在常见缩放下观察两块轮廓和透明边缘。
3. 用深浅壁纸检查侧栏控制、焦点与文字，调整遮罩后确认该值可保存。真实 Windows 磨砂、系统图标缓存和安装效果以隔离安装验收为准。
