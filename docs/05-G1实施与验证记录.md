## 实现边界

- 暂存版本和历史版本不自动清理。新版本启用前对默认配置及所有已有实例配置/存储的副本试运行；试加载无真实通知和警报写入权限。
- 升级事务保存旧实例配置/存储快照，旧目录保留；并发配置修改会拒绝本次切换。相同内容重复导入不使会话失效；旧页面不能以新版本身份握手。
- 数据库保存窗口逻辑位置/尺寸及浮窗置顶状态；移动/缩放后延迟合并保存，显式隐藏和退出前补存。后台启动保持无可见窗口，显式呼出时重建保存的浮窗。销毁全部视图不重置浮窗归属；关闭单个浮窗才归位。
- 登录启动只在用户切换选项时写本应用 HKCU Run 值，默认不自动开启。当前未执行真实登录/重启验收，不将代码存在标为通过。
- G1 桌面验收仍沿用普通桌面启动身份保护。`scripts/verify-g1.cmd` 记录独立阶段协议和应用版本，旧 G0 报告不能通过 G1 入口。模板双实例必须由各自真实页面按钮与 SDK 保存并回传证据，不能用 Rust 接管会话冒充页面完成。
- 桌面开发/构建前置命令直接使用本机 Node.js 和项目依赖，避免依赖 Codex 内部 pnpm 路径；包管理器入口仍保留，未安装全局包管理器或改动 PATH。
- 100/125% 缩放、副屏移除、不同 Windows 设备及长期稳定性继续保留未验证；G2 行情与警报尚未开始。
