## 网页交互清单

- 打开 [本机组件验收台](http://127.0.0.1:43187/)，或双击 [启动网页工具](../scripts/start-component-review.cmd)。命令行入口为 `node scripts/component-review.mjs`，无需安装新依赖。
- 支持搜索、分类与状态筛选、保留／裁剪／待定单选、验证结果、实测版本及问题备注；每项附原项目、固定版本及移植来源说明链接。
- 修改后自动保存草稿到 `artifacts/component-review/draft.json`，重开同一网页可继续填写；“导出备份”可下载当前结果。
- 完成后点击“提交筛选结果”→“提交到本机”，在 `artifacts/component-review/submissions/` 保存 JSON 和 Markdown 快照。允许提交部分进度，未填写项仍保留未筛选／待验证状态。
- 提交后在聊天中告诉我“已提交”，我即可按 `artifacts/component-review/latest-submission.json` 读取最新结果并汇总。

下方表格已同步当前有效选择：5项保留、53项未选择，验证结果均为待验证。网页修改自动保存到本机。

- 每项在“保留、裁剪、待定”三栏中选择一栏，将 `☐` 改为 `☑`；现有勾选来自本次提交。

- 筛选选择与验证结果分别记录：可以保留尚未验证的组件，也可以裁剪已验证通过但不需要的组件。
