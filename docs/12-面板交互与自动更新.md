# 面板交互与自动更新

日期：2026-11-14。主程序0.5.0，数据库继续为v4，组件接口继续为v1。用户已确认本轮交互，并改为公开源码、在同一仓库打包发布；已授权现有改动提交推送及自动打包生成草稿，正常安装与公开发布另行确认。

## 已实现

- 面板真实窗口滑入/滑出，分别0～1000毫秒，默认250毫秒；0为立即显隐。原生移动期间按原显示器右边界裁剪，结束后恢复完整几何，不抢焦点。
- 桌面空白主键双击默认启用，可在面板设置中关闭。按系统双击间隔和距离判定，拒绝注入点击及组合键；监听回调只排队并转交系统，Shell目标和可访问性角色查询由独立线程执行。不能确认空白目标时不触发。
- 快捷键、双击显式打开后保持展开。吸边悬停打开后，移出即开始收起；没有旧900毫秒延迟。输入、拖动、缩放、菜单、对话框和组件详情期间暂缓，操作结束后复核。全局隐藏状态下桌面双击不恢复组件，沿用托盘和显式快捷键恢复规则。
- 桌面与面板共用 `WidgetSurface`、图标菜单及缩放入口；使用项目自绘SVG图标，避免新增整套界面库。面板去掉品牌标题、文字组件标题及底部常驻设置，只保留添加、设置、收起图标。
- 面板组件自由拖动和调整尺寸。逻辑坐标保存在每实例独立的 `panel_layout:<实例ID>` 偏好；不覆写桌面几何或桌面尺寸。显示器变窄只收缩当前显示，不覆盖偏好；极窄工作区提供滚动并尊重组件最小尺寸。新位置和尺寸保存失败显示错误。
- 应用设置提供手动检查、可关闭的自动检查、更新说明、下载进度及确认安装。启动15秒后及每6小时检查，后台检查不弹窗口。下载由官方插件验签，且要求签名版本与清单版本一致；安装前保存布局并产生校验通过的SQLite一致备份。安装期间后台警报暂停，安装器使用 `/UPDATE`，不进入卸载清除数据分支。
- 应用更新沿用网络设置的直连、系统代理、HTTP或SOCKS5意图；开发和隔离运行拒绝实际安装更新。

## 自动打包与公开分发

源码与发行：[Cosmocraft996/SoulDesk](https://github.com/Cosmocraft996/SoulDesk)，按用户最新决定改为公开，在当前仓库打包和发行。

- `.github/workflows/check.yml`：main提交、合并请求或手动触发，运行格式、前端、Rust核心和资源构建检查。
- `.github/workflows/release.yml`：`v<版本>`标签或手动触发；核对三处版本、当前仓库公开及签名配置，再构建Windows x64 NSIS、签名和 `latest.json`，生成发布草稿。
- 同仓库发布使用内置GITHUB_TOKEN，工作流只授予Contents写权限，无需个人访问令牌；发布说明单独提供，不上传裸程序。
- 发布草稿不会更新公开下载入口。检查工作流成功与产物后，再在发行仓库公开发布；应用只检查已公开的最新正式版本。
- `node scripts/release.mjs --verify-installer` 核对真实安装包的内容签名、可信说明签名及版本绑定，输出SHA-256。

已配置两个当前仓库Secrets：`TAURI_SIGNING_PRIVATE_KEY`、`TAURI_SIGNING_PRIVATE_KEY_PASSWORD`。公开配置只含验签公钥。

不再需要RELEASE_TOKEN。用户已明确授权提交、推送及触发自动打包生成草稿。此前创建的独立发行仓库不再用于本项目打包，未删除或发布产物。

本机密钥位于被Git忽略的 `artifacts/release-keys/updater.key`，密码为同目录 `updater.password`。需要另行安全保管；丢失私钥后不能继续向已安装客户端发布同一签名身份的更新。公开测试夹具只含公钥、已签名测试文本和签名，不含私钥。

## 本地命令与交付

本地候选：`artifacts/SoulDesk_0.5.0_x64-setup.exe`；更新签名为同名 `.sig`。交付清单为 `artifacts/delivery-manifest-panel-050.json`，记录散列、最终程序和检查边界；没有安装或在线发布。

```powershell
pnpm check
pnpm test:web
node scripts/desktop.mjs test --locked --lib
node scripts/desktop.mjs check:rust --locked --all-targets
pnpm build
node scripts/release.mjs --verify-installer
node scripts/verify-panel.mjs
```

本机构建脚本从忽略目录读取已有私钥，CI从Secrets注入；不修改全局代理、PATH或Rust默认版本。当前沙箱内Rust构建脚本曾持续占用CPU无进展，已停止该次进程；在允许编译器正常运行的独立进程中，检查和构建通过。

0.4.0没有更新客户端，需要先手动安装一次0.5.0，后续版本才可使用应用内更新。正常安装和警报会中断，须由用户安排：从托盘退出SoulDesk，保留校验备份，在独立资源管理器启动本轮安装包；已有安装使用 `/UPDATE`，保留应用标识和数据目录。旧 `scripts/verify-upgrade.cmd` 及11中的清单只对应0.4.0，不用于本轮安装。
