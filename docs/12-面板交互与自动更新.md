# 面板交互与自动更新

日期：2026-11-14。主程序0.5.0，数据库继续为v4，组件接口继续为v1。用户确认公开源码并在同一仓库打包发布。现行发行流程见下方「自动打包与公开分发」。

## 已实现

- 面板真实窗口滑入/滑出，分别可调 0～1000 毫秒，默认各 100 毫秒。0 表示立即显隐。原生移动期间按原显示器右边界裁剪，结束后恢复完整几何，不抢焦点。
- “背景遮罩”默认 50%，单独一排。“滑入、滑出”在下一排等宽并排。侧边设置与管理窗口共用偏好设置，修改后立即应用并自动保存。新默认值用于缺少相应偏好的设置，已保存值继续生效。
- 桌面空白主键双击默认启用，可在面板设置中关闭。按系统双击间隔和距离判定，拒绝注入点击及组合键；监听回调只排队并转交系统，Shell目标和可访问性角色查询由独立线程执行。不能确认空白目标时不触发。
- 面板快捷键注册失败时，可从组件管理进入快捷键设置，更换键位或释放占用后重新保存原键。注册成功或关闭快捷键后，提示随状态消失。
- 当前显隐、鼠标触发和锁定后置底规则见本文的[侧边面板显隐与桌面层](#2026-11-18侧边面板显隐与桌面层)。下方日期记录保存对应构建的行为及验收证据。
- 多屏共用一个挂件。拖动按指针所在屏幕的工作区和缩放停靠，松开记录屏幕、边和高度。面板从挂件所在屏幕展开，断开停靠屏幕时回到主屏。
- 桌面与面板共用 `WidgetSurface`、浮动工具栏与缩放入口。删除实例使用垃圾桶，排在“更多功能”前面。面板组件的“移动到分组”使用带箭头的文件夹，直接放在工具栏。窄组件只折叠移入/放回、置顶和隐藏，“更多功能”也可打开行情组件的自选与警报。组件管理可从面板顶部或托盘打开。
- 展开与收起使用屏幕右侧中部同位置的开关，箭头随状态变化。顶部工具区的四宫格打开“管理组件”，滑杆打开“面板设置”。锁定时显示实心图钉和高亮底色，解锁时显示带斜线的空心图钉。
- 2026-11-16将×从隐藏改为删除实例，弹出二次确认，默认聚焦取消；确认后调用现有实例删除路径。眼睛按钮单独负责隐藏，保留配置和后台规则。隐藏或删除面板内组件时，重建容器保留显式展开状态。2026-11-15的×隐藏行为及其证据仅作为历史记录。
- 面板组件自由拖动和调整尺寸。逻辑坐标保存在每实例独立的 `panel_layout:<实例ID>` 偏好；不覆写桌面几何或桌面尺寸。显示器变窄只收缩当前显示，不覆盖偏好；极窄工作区提供滚动并尊重组件最小尺寸。新位置和尺寸保存失败显示错误。
- 应用设置提供手动检查、可关闭的自动检查、更新说明、下载进度及确认安装。启动15秒后及每6小时检查，后台检查不弹窗口。下载由官方插件验签，且要求签名版本与清单版本一致；安装前保存布局并产生校验通过的SQLite一致备份。安装期间后台警报暂停，安装器使用 `/UPDATE`，不进入卸载清除数据分支。
- 应用更新沿用网络设置的直连、系统代理、HTTP或SOCKS5意图；开发和隔离运行拒绝实际安装更新。

## 自动打包与公开分发

源码与发行：[Cosmocraft996/SoulDesk](https://github.com/Cosmocraft996/SoulDesk)，按用户最新决定改为公开，在当前仓库打包和发行。

- `.github/workflows/check.yml`：main提交、合并请求或手动触发，运行格式、前端、Rust核心和资源构建检查。
- `.github/workflows/release.yml` 核对三处版本、仓库公开状态及签名配置，再构建 Windows x64 NSIS 安装包、签名和 `latest.json`，上传到发行草稿。
- 推送与源码版本一致的正式标签（如 `v0.5.2`）视为发布确认。核验草稿后，工作流公开对应发行并设为最新正式版。手动运行只生成并核验草稿，即使手动选择的是版本标签。
- `node scripts/release.mjs --verify-installer` 核对安装包签名和版本绑定，输出 SHA-256。工作流通过 `--verify-draft --upload-manifest` 生成更新清单并比对三个已上传附件的摘要。两个 Windows x64 更新项均使用该版本的公开安装包地址，避免 GitHub REST API 的匿名请求限流。
- 同仓库发布使用内置 `GITHUB_TOKEN` 和 Contents 写权限。应用读取公开最新正式版的 `latest.json`。

已配置两个当前仓库Secrets：`TAURI_SIGNING_PRIVATE_KEY`、`TAURI_SIGNING_PRIVATE_KEY_PASSWORD`。公开配置只含验签公钥。

本机密钥位于被Git忽略的 `artifacts/release-keys/updater.key`，密码为同目录 `updater.password`。需要另行安全保管；丢失私钥后不能继续向已安装客户端发布同一签名身份的更新。公开测试夹具只含公钥、已签名测试文本和签名，不含私钥。
