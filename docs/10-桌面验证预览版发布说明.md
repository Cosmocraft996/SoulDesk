# SoulDesk 桌面验证预览版

版本：`v0.3.3-desktop-preview.1`；平台：Windows x64。

这是独立桌面宿主的验证预览包。正常应用的管理窗口、行情视图和数据迁移尚未改造成新桌面形态；本包不会替换已有 SoulDesk 安装。

## 启动

1. 将整个 ZIP 解压到可写目录，不要只取出可执行文件。
2. 双击“启动桌面验证.cmd”。系统需已安装 Microsoft Edge WebView2 Runtime。
3. 程序先在隐藏容器试加载时钟、卡片原包，再显示两个桌面组件与右侧面板，并完成程序链路检查。
4. 可以编辑保存组件内容，在桌面与侧栏之间切换、调节面板宽度和背景遮罩。
5. 完成后点侧栏底部“结束本次验证”→“确认结束”。未手动结束时，30 分钟后自动退出。

每次运行使用独立目录。组件包、测试 SQLite、WebView 数据与报告都位于解压目录下的 `artifacts`，不会打开或迁移正常应用数据库。侧栏收起后，可从桌面组件顶部重新打开；窗口显示和恢复不主动夺取焦点，点击输入时才处理键盘激活。

## 包内文件

- `desktop-probe.exe`：Release 构建的独立探针。
- `启动桌面验证.cmd`：以正确工作目录启动真实组件验证。
- `artifacts/local.example.clock-0.1.1.zip`、`artifacts/local.example.card-0.1.0.zip`：经过原包加载链路的普通组件。
- `bundle-manifest.json`：对应源码提交、文件大小与 SHA-256。
- `third-party/window-vibrancy-0.8.1-MIT.txt`：保留的第三方许可。

本包不含本机测试库、WebView 缓存、凭证或原始诊断记录。GitHub Release 另附 ZIP 的 SHA-256 与发布清单。

## 验证范围

本机 Windows 11 25H2、主屏 150% 下，已完成桌面附着、普通应用覆盖、Win+D、置顶返回、侧栏几何与任务栏、聚焦/失焦磨砂的分项观察；原时钟/卡片 ZIP、SDK、保存、隐藏释放、展示往返、失败恢复及跨应用输入也已有程序和人工证据。

源码通过 Rust 87 项、Node 15 项、前端类型、资源构建及格式检查。本包执行 Release 构建和逐文件完整性校验；此前完整人工验收来自同源隔离探针，不将构建成功当作额外一次人工复测。

磨砂使用未公开的窗口级 Accent Acrylic 入口；其他 Windows 版本、缩放及设备未验。副屏已枚举，未完成副屏交互验收。本包不包含正式行情桌面整合、正常数据迁移或完整安装升级流程。

## 从源码构建

在源码仓库完成依赖准备后，先构建网页资源和组件包：

```powershell
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vite/bin/vite.js build
node scripts/build-example.mjs
& "$env:USERPROFILE\.cargo\bin\cargo.exe" build --locked --release --manifest-path src-tauri/Cargo.toml --bin desktop-probe --features tauri/custom-protocol
```

完成源码提交、保持工作区干净后运行：

```powershell
node scripts/build-desktop-preview.mjs
```

产物位于 `artifacts/releases`。打包器只收录明确清单，并在内存中解包逐项核对；已有同名产物时拒绝覆盖。
