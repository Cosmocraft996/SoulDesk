# 架构审计收尾

本批完成先前审计余下的金融来源、文件读写和剪贴板权限细分，并同步README速查与需求、技术文档。构建与版本校验、集中能力登记和生命周期、资源打包、公开请求缓存、首批权限迁移分别见14～18。

金融组件使用原传输、缓存、报价和展示规则。汇率继续显示原外部国旗，独立声明HTTPS图片。其余七款使用包内资源并升至0.1.1。币安行情和价格警报沿用专用网关。

上述8款显式声明`documents.drop`，保留原有桌面和侧栏窗口的拖放处理方式。文件仍由用户在原生对话框选择。相册目录和收纳盒授权继续走各自入口。

剪贴板的控制权限对应状态、弹窗和配置。历史组件单独声明历史、复制和粘贴。AI剪贴板分别声明搜索及工具。跨应用粘贴继续核对用户开关、专用弹窗及已捕获目标。采集和搜索快捷键在执行前检查对应权限。组件的历史、设置和开关沿用原存储。

本批17个组件包升版。旧`content.read`、`documents.user`、`clipboard.manage`仍适用旧版组件，新旧同类权限不可混用。用户先升级宿主，再显式升级组件。升级及数据快照复用正式组件管线。源码交付和剩余人工验收分别记录，原云功能继续按用户确认后置。

61个标准包已重建并通过版本校验。逐文件对比841项资源，只有17个目标清单变化，其余44包摘要相同。当前预置清单已全部移除上述旧权限。构建、645项核心回归、410项前端检查和最终清单的23项专项检查通过。核心回归覆盖单独授权和越界拒绝、采集禁用、旧包和非空实例升级。两项既有真实OKX检查按原约定跳过。包及版本对照见`artifacts/audit-closeout-packages-20261118.json`。

首轮旧包升级因汇率国旗缺少独立图片授权而停止，正式升级流程保留了0.1.0。修正后保留原国旗地址及HTTPS图片权限，通过版本校验升至0.1.2。

最终正式构建通过17份真实旧ZIP的导入、显式升级和两阶段重启，共36项。旧摘要的资源策略、隔离实例设置、显示状态和非空存储均保留，含自选与手工持仓、导图、服务器设置、大头贴地址及剪贴板配置版本。报告在`artifacts/desktop-integration-audit-closeout-upgrade-final-20261118.json`。

同一构建的汇率和图片转换专项共26项通过，包含两个实例的保存、面板切换和重启。汇率的原国旗实际加载，外部汇率接口仍返回403，页面显示失败，同币种换算通过。图片转换通过HEIC解码及五种输出格式检查。原生文件对话框、真实系统剪贴板操作及正常安装升级沿用人工验收范围。验收报告见 [验证汇总](../artifacts/audit-closeout-verification-20261118.json)。未提交、未安装，未打开正常用户数据库。
