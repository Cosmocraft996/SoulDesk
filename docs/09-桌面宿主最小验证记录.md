先构建前端资源，再启动独立平台探针：

```powershell
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vite/bin/vite.js build

# 可显式指定新的报告绝对路径：
```

报告同名无扩展目录保存本次 WebView 配置/缓存与 `panel.json`；报告和目录已存在时拒绝覆盖。原 `App`、正常 Core、数据版本和行情/警报未迁移。查询参数只选择页面，后台命令仍要求本次窗口身份、能力白名单及仅注入顶层的随机令牌。面板与夹具能力分成两份最小白名单。

平台附着采用已有 Explorer 桌面视图父窗口，改变本次组件的 `WS_POPUP/WS_CHILD` 后 `SetParent`，转为父客户区坐标定位。工具窗口样式排除任务切换入口；显示使用 `SW_SHOWNOACTIVATE` / `SWP_NOACTIVATE`，不永久禁止用户激活。未向 Explorer 发送重建消息、未改系统缩放/网络、未注册全局快捷键。

侧栏最初使用透明窗口及 Tauri `Effect::Acrylic`，后按人工反馈改为原生 `Effect::Blur` 和独立背景叠层，原生主题明确设为深色；不以网页模糊冒充系统磨砂。每秒按当前显示器工作区重算几何，只在变化时调整，比例保存与组件配置无关。面板重建确认旧标签销毁后再创建，重新读取保存比例。

来源：[微软 SetParent 约束](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setparent)、[系统背景材质](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)、[Tauri 窗口特效](https://docs.rs/tauri/2.12.5/tauri/webview/struct.WebviewWindowBuilder.html#method.effects)、[事件循环退出](https://docs.rs/tauri/2.12.5/tauri/struct.App.html#method.run_return)。Tauri 2.12.5 与 Tao 0.37.2 的拥有实现源码已核对；未复制参考项目的宿主代码。
